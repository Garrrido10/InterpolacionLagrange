# InterpolacionLagrange
El proyecto está organizado dentro del paquete interpolacion:

InterpolacionLagrange.java: Implementación completa del método de interpolación polinomial de Lagrange, incluyendo validación robusta de arreglos y manejo de excepciones para nodos repetidos o nulos.

Main.java: Clase principal para la ejecución de pruebas numéricas y validación de resultados en consola.

Nota: Contiene la integración y referencia para el método de Diferencias Divididas de Newton visto en clase.

## Requisitos del Entorno

Para compilar y ejecutar este proyecto en tu equipo local, asegúrate de contar con:

Java Development Kit (JDK): Versión 11 o superior.

Entorno de Desarrollo (IDE): IntelliJ IDEA (recomendado), Eclipse o NetBeans.

## Instrucciones de Ejecución

Clonar o descargar este repositorio en tu equipo local

Abre tu IDE de preferencia e importa el proyecto como un proyecto Java estándar.

Localiza la clase Main.java dentro del paquete interpolacion.

Ejecuta el archivo Main para visualizar en la consola los nodos de prueba, el punto evaluado y el resultado de la interpolación polinomial.
